# dominicschenone.com

Source for the Schenone Consulting website: custom web development, business intelligence, and data engineering without the enterprise overhead.

- `website/`: Quarto source (pages, styles, Work-page case studies). See [website/README.md](website/README.md) for how to edit, build, and add projects.
- `docs/`: the rendered site that GitHub Pages serves. Generated by `quarto render`; don't edit by hand.

Hosted on GitHub Pages behind Cloudflare, at [dominicschenone.com](https://dominicschenone.com).
